# 清序 v0.1.1 品牌与真机验收设计

日期：2026-06-07  
平台：Flutter 手机端  
目标版本：`v0.1.1+2`  
发布标签：`v0.1.1`

## 1. 目标

本次迭代完成首版品牌包装，并收口 `v0.1.0` 真机验收中发现的问题：

- 使用已确认的 A3 折页任务纸标志替换 Flutter 默认图标。
- 统一 Android、iOS 的应用名称、启动画面和图标资源。
- 修复无备注任务无法展开编辑、删除的问题。
- 修复仅日期任务在当天 09:00 后无法选择立即提醒的问题。
- 修复“立即提醒”在交互和数据库处理后已经过期、导致系统拒绝排程的问题。
- 在华为鸿蒙 4.2 真机上完成安装、数据持久化和本地通知验收。

本版本不调整首页布局和交互动效。UI 动画优化进入下一轮独立设计。

## 2. 已选品牌方向

采用方案 A3：折页任务纸。

标志由以下元素构成：

- 鼠尾草绿圆角方形底板。
- 暖米白任务纸，右上角有清晰折页。
- 纸面使用简化的鼠尾草绿任务横线。
- 珊瑚红对勾作为唯一高对比焦点。

标志不使用文字、渐变、复杂阴影或细小装饰。缩小到系统通知和桌面图标尺寸后，折页与对勾仍应可辨认。

## 5. 启动画面

启动画面只展示 A3 标志，不放版本号、宣传语或加载提示。标志宽度约占手机短边的 22%，保持足够留白。

原生启动画面与 Flutter 首帧使用相同暖米白背景，减少启动切换时的闪白和跳变。启动画面不承担业务初始化提示，通知或数据库初始化失败仍由应用内反馈处理。

## 6. 通知可靠性

“立即提醒”不是直接使用用户开始保存时的时间：

1. 领域规则为平台排程预留 5 秒。
2. 通知出站队列真正处理任务时，若“立即提醒”的排程已经过期，则按处理时刻重新排到 5 秒后。
3. 只有 `immediate` 类型允许重排；普通历史提醒不会被误补发。
4. 排程失败时保留通知任务和错误信息，供应用启动或回到前台时重试。

Android 使用非精确、允许待机模式的本地闹钟，不承诺秒级到达；验收标准是系统成功登记提醒，并在合理系统调度窗口内出现。
